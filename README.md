# Linux System Monitor

A lightweight Python-based system monitoring tool for viewing
CPU, RAM, disk, network, process, and overall system health.

Built with Python and `psutil`.

## Features

- CPU usage monitoring
- RAM usage monitoring
- Disk usage monitoring
- System uptime
- Operating system information
- CPU core information
- RAM total, used, and available
- Disk total, used, and free
- Network interface information
- Network traffic statistics
- Upload/download speed
- Top processes by CPU usage
- CPU/RAM/Disk resource status
- Configurable warning thresholds
- Overall system health score
- Continuous watch mode
- Local system usage logging
- JSON system report generation
- Lightweight CLI interface

## Requirements

- Python 3.10+
- `psutil`

## Installation

Clone the repository:

```bash
git clone <https://github.com/Prince8879/linux-system-monitor.git>
cd linux-system-monitor
```
